# Deep_Learning_with_Parametric_and_Prediction_Uncertainty

The following repository contains the sources code used for frameworks proposed in the paper *Deep Learning Frameworks for Metamodeling of Nonlinear
Stochastic Dynamic Systems under Parametric and Predictive
Uncertainty* by Haimiti Atila and Seymour M.J. Spence. 


##Lists of Abbreviations:

* Multiple layer perceptron with LSTM : MLP-LSTM
* Message-passing neural network with LSTM : MPNN-LSTM
* Autoencoder with LSTM : AE-LSTM
